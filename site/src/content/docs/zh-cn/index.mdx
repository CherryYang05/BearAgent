BearAgent 是一个 local-first 的个人 Agent Runtime。Runtime 是模型之外那层真正负责执行的软件：它把
目标交给模型，把模型提出的 Tool 请求变成受限动作，并把发生过的事实保存下来。

目前最适合学习的场景很小：Agent 在指定 workspace 中查找、读取和比较资料，只把完整结果写进
`outputs/**`。小场景让我们能把模型调用、文件边界、预算、持久化和失败路径逐一看清。

## 怎样判断页面在讲什么

每页都带有内容状态：

| 状态 | 含义 |
|---|---|
| `implemented` | 当前代码和测试已经支持，可以按页面给出的入口复现 |
| `design` | 已接受的 BearAgent 设计，但不等于全部实现 |
| `planned` | Roadmap 中的方向，还不能当作现有能力 |
| `concept` | 通用 Agent 知识，不用于证明 BearAgent 行为 |
| `mixed` | 一页同时讲当前与未来，正文必须逐段说明边界 |

工程事实仍以仓库 `docs/`、代码和测试为准。学习站负责把这些事实组织成一本能连续读下去的书，
不会复制一套新的项目状态。
