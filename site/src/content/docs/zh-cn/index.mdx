不是先读完所有 Spec，而是先看到命令怎样产生 Run ID、Artifact 和 Event，再理解 Runtime 为什么
限制路径、预算、权限和重试。

## 这套文档分三层

1. **使用文档**回答“现在怎么运行、配置和排错”，以[CLI 完整手册](/zh-cn/guides/cli/)为入口。
2. **学习与架构**回答“一次请求怎样流动、为什么这样取舍”，从[P1 学习路线](/zh-cn/learn/)进入。
3. **开发者文档**回答“代码在哪里、哪些边界不能改坏、什么测试能证明”，从
   [代码路线](/zh-cn/development/)进入。

工程事实仍以仓库 `docs/`、代码和测试为准。站点不会把未来 Feature 写成当前能力，也不会用学习页
代替 Spec、ADR 或 Plan。
